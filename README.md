Projeto desenvolvido em Python utilizando comunicação entre cliente e servidor.

Execução
Para executar o projeto, é necessário abrir dois terminais na pasta dos arquivos.

1. Servidor
No primeiro terminal, execute: python servidor.py
O servidor ficará aguardando a conexão do cliente.

3. Cliente
Em outro terminal, execute: python cliente.py Após a conexão, será solicitado o login.

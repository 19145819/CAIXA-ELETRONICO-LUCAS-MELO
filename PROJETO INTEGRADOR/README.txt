Professor, segue o código-fonte do projeto do Sistema de Caixa Eletrônico.

O projeto foi dividido em dois arquivos, conforme a arquitetura cliente-servidor:

• `servidor.py` — responsável por receber as conexões, autenticar o usuário e processar as operações de depósito, saque e consulta de saldo.

• `cliente.py` — responsável pela interação com o usuário e pelo envio das solicitações ao servidor.

Os dois arquivos devem estar na mesma pasta para a execução do projeto.
